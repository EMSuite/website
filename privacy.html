Privacy

4DSTEM Studio and Electron Microscopy Studio collect no data. Everything runs on your Mac. There are no accounts, no analytics, and nothing is sent to me. One exception is the Materials Project lookup in 4DSTEM Studio, which you start yourself and which sends your own API key and the material ID to materialsproject.org.

The apps downloaded from this website check for updates with Sparkle. After asking you once, an app reads a small update feed from mac4dstem.com about once a day; you can turn this off in its Settings. The request carries what any web request carries, such as your IP address and the app's name and version, and no system profile. An update you choose to install is downloaded from GitHub. The App Store versions do not check: the App Store updates them.

This website sets no cookies and runs no analytics. It is hosted on GitHub Pages, which keeps the usual server logs (GitHub privacy statement). If you e-mail me, I keep your message only to reply. Under the GDPR you can ask me to access, correct or delete your data at any time.

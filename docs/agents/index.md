# Agents

How an AI agent such as Claude or Codex connects to 4DSTEM Studio and Electron Microscopy Studio on the same Mac, looks at the data and runs analyses.
<p class="lede">An agent on your Mac can look at what the app's windows show and, when you allow it, run an analysis while you watch.</p>

These pages are being written. They will cover:

- **Connecting** Claude, Codex or any MCP client to the app.
- **Permissions**: what an agent may see and do, and the switches in Settings that allow it. Everything is off until you turn it on.
- **The record**: every setting an agent changes is written to the app's Output, so a result an agent produced can be repeated by hand.
- **Workflows**: worked examples, from describing a dataset to tuning a detection and running one analysis over several files.

The app talks to the agent on your Mac only. It sends nothing anywhere itself.

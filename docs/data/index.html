Example data

Data to learn the apps on. Every dataset here is public and is listed with its source, its licence and how to cite it.

No data file is kept on this site. Each dataset is linked at the place where its authors published it, so you always get their current version and their own description.

In the apps

Both apps carry demo data, so a first look needs no download.

App How to open it What it is
4DSTEM Studio Try Demo Data on the welcome screen A small synthetic 4D-STEM dataset on which every workspace works. See First look.
Electron Microscopy Studio Try Demo Data on the welcome screen Generated examples, and four public files: the nickel EBSD patterns and their master pattern, a two-phase orientation map and an SEM-EDS spectrum (credits below).

Using a dataset

Licence

CC BY 4.0 lets you use, share and adapt the data when you name its authors. Cite the dataset as above in anything you publish with it. The licence shown here was read from each record; the record itself is what counts.

Some of these files are large. Before you open a large 4D-STEM scan, read Large datasets: crop or bin it with Open with Options… so that it fits your Mac.

More datasets are added as the tutorials are written. Each tutorial names the dataset it uses.

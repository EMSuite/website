Electron Microscopy Studio · Get started

The window

Applies to Electron Microscopy Studio 2.1 and later

One window per file. The sidebar lists five workspaces, one for each kind of data.

Workspaces

The sidebar on the left lists the workspaces, top to bottom. Each has a shortcut. A workspace with more than one part lists its parts below it.

Workspace Key Parts What you do there
Imaging ⌘1 Image, FFT TEM and SEM images and their Fourier transform
Diffraction ⌘2 Camera length, d-spacings, indexing and zone axis
EBSD ⌘3 Patterns, Indexing, Maps EBSD and TKD: patterns, indexing and orientation maps
Spectroscopy ⌘4 EDS, EELS EDS and EELS spectra and spectrum images
Results ⌘5 Review and export the numbers

The file decides what is available. A workspace or a part with no data for the open file is dimmed, and says why when you point at it; see Troubleshooting. Going back to a workspace returns to the part you left it in.

The picture and the inspector

The middle of the window shows the data: the image, the pattern, the map or the spectrum. The inspector on the right holds the settings and the results of the part you are in. Show or hide it with ⌥⌘I.

Output

Output, below the picture, is the log: every step the app ran, with its numbers and any warning. Show or hide it with ⌃⌘L. Read it after each step.

Running a step

Most results update while you work. A step that goes through a whole scan, such as indexing, runs when you ask for it.

Command Key
Workspace › run the current step (the menu names it) ⌘R
Workspace › Stop ⌘.

Command Key

File › Reopen Last Session ⇧⌘O
File › Close (the image, dataset, map or spectrum image shown) ⌘W
File › Close Window ⇧⌘W

File › Export Transform… ⌥⌘E
File › Export Results… ⌥⇧⌘E
Image › Pan, Distance, Angle, Profile ⌃⌘1 to ⌃⌘4
Show or hide the sidebar ⌃⌘S

In the EDS part, ⌃⌘0 to ⌃⌘4 choose the region tools instead: select, rectangle, ellipse, polygon and line.

Settings

Settings… in the app menu (⌘,) has three parts: Images, Agents and Software Update.

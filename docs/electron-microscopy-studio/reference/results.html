Electron Microscopy Studio · Reference

Results

Applies to Electron Microscopy Studio 2.1 and later

Results lists every finished measurement of the open file in one table, whichever part made it. This page lists every control of the workspace.

Show

One switch per kind of result, each with its count.

Kind Made in
Marks Image: distances, angles and profiles
FFT Spots FFT
Calibration Diffraction
Rings and spots Diffraction
EDS composition EDS
EELS thickness, EELS edges EELS

A result

Select a row; the Info tab shows it.

Row What it says
Result The name of the measurement
Value The number with its unit
Source Where on the image it was measured
Record What was recorded with it
Method How it was measured

A result is removed in the part that made it; the Info tab names that part. Below the result, Source Image lists the file, the object, the size, both axes and any notes of the reader.

Session and export

Session shows the session file the measurements are kept in, with Show in Finder and Choose Session File…; see Sessions. All results as CSV… exports every finished measurement of the file. It is dimmed while nothing is measured yet, or while a read is running.

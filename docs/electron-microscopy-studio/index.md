# Electron Microscopy Studio

Documentation for Electron Microscopy Studio, the native macOS application for TEM and SEM data: getting started, data, tutorials, reference and troubleshooting.
<p class="lede">TEM and SEM data on the Mac: images, diffraction, EBSD and spectra, each in its own workspace.</p>

These pages are being written. They will follow the app's workspaces from top to bottom:

| Workspace | What the tutorial covers |
|---|---|
| Image | The calibrated image: contrast, distances, angles and profiles |
| FFT | The Fourier transform, a live FFT on a region, lattice spacings |
| Diffraction | Camera length, d-spacings, indexing and zone axis |
| Patterns | EBSD and TKD patterns: the scan and its pattern processing |
| Indexing | Hough and dictionary indexing of the scan |
| Maps | Orientation and phase maps, grains and pole figures |
| EDS | Spectrum images: elements, maps and composition |
| EELS | Thickness maps, core-loss edges and composition |
| Results | Reviewing and exporting the numbers |

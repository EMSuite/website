Electron Microscopy Studio · Your data

Sessions

Applies to Electron Microscopy Studio 2.1 and later

The distances, angles and profiles you draw on an image are kept in a session file beside the image. Your data file is never changed.

The session file

The session file sits in the same folder as the image and has its whole name with .mactem.h5 added. For scan.dm4 it is scan.dm4.mactem.h5.

Save

In the Image part of Imaging, choose File › Save to Session (⌘S).

The first time, a save panel shows the session file's name in the image's folder. Click Save without changing the name or the folder: the app finds the file again by them. macOS needs this one click to let the app write beside your image. Later saves need no panel.

When you close an image with marks that are not saved, the app asks first.

Open again

Open the image as usual. The marks from its session file come back with it.

If macOS did not give the app the session file, the image's row says "session file needs access". In the Measure section of the inspector, click Choose Session File… and pick it. Show in Finder there shows where the session file is.

The last session

File › Reopen Last Session (⇧⌘O) opens the files you had open when you last quit, in the place you left. It is offered, never done at launch, so a large file is not loaded before you ask.

Moving data

Move or copy the image and its .mactem.h5 file together and keep their names. A session file belongs to the image it was saved for.

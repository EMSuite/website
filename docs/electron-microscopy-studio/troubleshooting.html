Troubleshooting

Applies to Electron Microscopy Studio 2.6 and later

The app says what is wrong in its own words. This page lists those messages and what to do about each.

A file does not open

"Can't read …" in the window. The file is listed but its content could not be read. The sentence underneath gives the reason. If the file was on a disk or share that was away, reconnect it and click Try Again.

An alert says the app can't open this file. The file is not one of the formats the app reads, or it is damaged. The alert names what the reader found. A file that was cut short while copying has to be copied again from the microscope computer.

The app asks for a folder

A NORDIF EBSD scan is read together with the Setting.txt and the background pattern beside it. macOS gives the app only the file you picked, so the app shows a panel on the scan's folder: choose that folder, or one around it, and click Allow. The app remembers the folder and does not ask again for scans inside it.

A workspace or a part is dimmed

Each part of a workspace needs its own kind of data. A dimmed one says why when you point at it:

The reason What it means
No file open holds an image Image, FFT and Diffraction work on an image. Open one, or choose File › New Simulation to simulate a pattern with none.
No file open holds an EDS spectrum image EDS needs a spectrum image with X-ray counts.
No file open holds an EELS spectrum image EELS needs an energy-loss spectrum image.
No file open holds EBSD patterns Patterns and Indexing need an EBSD pattern dataset.
No file open holds an orientation map Maps needs an indexed map.
The open images belong to a spectrum image, not a diffraction pattern The image is the survey image of a spectrum image. Diffraction needs a diffraction pattern.

A phase search finds nothing

Add Phase… asks the Materials Project, which needs an internet connection. Without one, open a CIF file in the same sheet: a phase added once, from either source, works offline. The search sends the elements, the formula or the entry id you type, and your own API key if you saved one in Settings › Materials Project.

The image has no scale

"Not calibrated: the scale bar counts pixels." The file carries no pixel size. Distances, profiles and particle sizes are then given in pixels. The Calibration section of the Image inspector shows what the file carries and where it came from.

"Pixels are not square". The file's two axes have different pixel sizes. The scale bar uses the horizontal axis.

A diffraction pattern without a scale. For the Diffraction workspace, record a standard under the same conditions, choose it under Standard, drag an annulus over one of its rings and click Calibrate on Ring.

Updates

The app checks once a day whether a newer version exists. To check now, choose Check for Updates… in the app menu. To turn the daily check off, clear Settings › Software Update › Check for updates automatically.

If an update does not install, download the current disk image from the Electron Microscopy Studio page and replace the app in Applications. Your settings stay.

An agent cannot connect

  1. Open Settings › Agents and turn on Let agents on this Mac look at open windows.
  2. Read Status. "On (port 47812), no agent has asked yet" means the app is listening and the agent has not reached it. "Could not open:" is followed by the reason.
  3. Click Copy Connection Command and paste it into Terminal once. The command holds the token; an agent set up with an older token is refused after New Token.

The agent can look but not act. Tools that change something need Let agents run analyses, which is off by default.

The agent is on another computer. The app answers only on the Mac it runs on. Run the agent on the same Mac.

Something else

Write to mail@mac4dstem.com or open an issue on GitHub. Say which version you use, the file format, and the message the app showed. Support has the contact details.

Methods and their references

Applies to Electron Microscopy Studio 2.1 and later

Each function the app computes itself, the reference it is checked against and how closely. 161 functions in 21 groups, from the app's parity table at 2.1.1.

The rule is the same for every row: the app matches the pinned version of the Python package within the tolerance that package's own tests use, never stricter. Readers, indices and metadata match exactly. Where a method has a paper, the reference names it. The numbers of the kits the app is built on are listed on the kits page, each with its own parity table.

Generated from docs/parity.md at v2.1.1, which also gives each row's test and notes. The page's tables leave those out.

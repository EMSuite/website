Index EBSD patterns on a Mac

Applies to Electron Microscopy Studio 2.1 and later

From a pattern file to an orientation map, with the methods and settings of kikuchipy and pyEBSDindex.

  1. Open an h5ebsd pattern file with Open Image… (⌘O). In EBSD › Patterns, set the processing and the detector geometry.
  2. In EBSD › Indexing, add a phase from the presets or from a CIF, and choose Hough, or Dictionary with an EMsoft master pattern.
  3. Click Index. Read the quality maps first, then the IPF map. Export the orientations as an EDAX .ang or an Oxford .ctf file.

A dictionary run can refine the orientations and the projection centre after indexing. EBSD Indexing lists every control.

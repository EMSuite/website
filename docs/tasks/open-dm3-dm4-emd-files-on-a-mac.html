Open DM3, DM4 and EMD files on a Mac

Applies to Electron Microscopy Studio 2.1 and later

Electron Microscopy Studio opens the files TEM software writes, natively on Apple silicon, with the calibration the microscope stored.

  1. Choose Open Image… (⌘O) and pick a DigitalMicrograph .dm3 or .dm4 file, a Velox .emd file, a TIFF or an MRC file.
  2. The image opens in the Imaging workspace. The Calibration section of the inspector shows the pixel size and the field of the file it came from. An image without one is marked "Not calibrated".
  3. Measure with the Distance, Angle and Profile tools, or save the picture with File › Export Image… (⇧⌘E).

The same command opens EDS and EELS spectrum images, SEM images and EBSD scans; each opens in its own workspace. File formats lists every format, and Image every control.

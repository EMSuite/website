How to install the apps, open your data and work through an analysis, step by step.

  • 4DSTEM Studio4D-STEM: calibration, virtual imaging, Bragg disks, strain and crystal maps, EDS beside the scan.
  • Electron Microscopy StudioTEM and SEM: images and their FFT, diffraction, EBSD, EDS and EELS.

  • Example dataThe public datasets the tutorials use, with source, licence and download.

How the pages are organised

Each app has the same five parts:

  • Get started: install the app and see a first result within minutes.
  • Your data: the file formats, large datasets, saved sessions and export.
  • Tutorials: one analysis from the open file to the exported result, with every setting explained.
  • Reference: each workspace and what its controls do.
  • Troubleshooting: answers to the usual problems.

Every page says which version of the app it applies to. The documentation describes the latest release; what changed from version to version is in the release notes of 4DSTEM Studio and Electron Microscopy Studio.

4DSTEM Studio · Get started

The window

Applies to 4DSTEM Studio 5.4 and later

One window per dataset. The sidebar lists the workspaces in the order an analysis usually takes.

Workspaces

The sidebar on the left lists the workspaces, top to bottom. Each has a shortcut.

Workspace Key What you do there
Prepare ⌘1 Inspect and calibrate the dataset
Imaging ⌘2 Virtual images and diffraction groups
Bragg Disks ⌘3 Detect Bragg disks and label them
Crystal Maps ⌘4 Strain, orientation and phases from Bragg disks
Reconstruction ⌘5 DPC, parallax and ptychography
Spectroscopy ⌘6 EDS spectrum images, alone or with the 4D scan
Results ⌘7 Review, save and export

A workspace with more than one task lists its tasks below it, for example Strain, Orientation and Phase mapping in Crystal Maps. ⌥⌘↓ and ⌥⌘↑ step through the tasks.

Spectroscopy needs a spectrum image; with a 4D scan alone it is not available.

The panes

The middle of the window shows the data: a diffraction pattern, and the scan as an image or a map. What you drag on one changes what the other shows.

The inspector

The inspector on the right holds the settings of the task you are in. Show or hide it with ⌥⌘I.

The bottom pane

Below the panes are Output and Lineage. Output is the log: every step the app ran, with its numbers and any warning. Lineage shows how each result was made, step by step. Show or hide the bottom pane with ⌃⌘L.

Read Output after each step. When a step is flagged there, for example a calibration that is not good enough for quantitative results, deal with it before you build the next step on it.

Running a task

Some results update while you drag, such as a virtual image. Others are computed over the whole scan when you ask for it.

Command Key
Analysis › Run Current Task ⌘R
Analysis › Cancel Analysis ⌘.

More shortcuts

Command Key
File › New Dataset Window ⌘N
File › Open Dataset… ⌘O
File › Reopen the last dataset ⇧⌘O
File › Export Result PNG… ⇧⌘E
File › Export Diffraction PNG… ⌥⌘E
Show or hide the sidebar ⌃⌘S

Settings

Settings… in the app menu (⌘,) has six parts: General, Appearance, Analysis, Materials Project, Agents and Advanced. The defaults follow py4DSTEM, so an analysis started here and one started in Python begin from the same values.

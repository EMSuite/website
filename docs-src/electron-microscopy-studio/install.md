<p class="lede">The app is free. It needs no Python, no other runtime and no account.</p>

## What you need

| | |
|---|---|
| Mac | Apple silicon |
| macOS | 26 or later |
| Download | About 42 MB |

## Install

1. [Download the disk image](https://github.com/EMSuite/Electron-Microscopy-Studio/releases/latest/download/Electron-Microscopy-Studio.dmg).
2. Open it and drag the app to your Applications folder.
3. Open the app from Applications. It is signed and notarized, so macOS opens it without a security warning.

The app starts with a welcome window that lists your recent files and the tutorials. [First look](/docs/electron-microscopy-studio/first-look.html) takes it from there.

## Update

The app looks for a new version once a day and offers it when there is one. To look now, choose <span class="ui">Check for Updates…</span> in the app menu. The switch for the daily check is in <span class="ui">Settings › Software Update</span>.

Looking for an update asks mac4dstem.com which version is current. Nothing else is sent; see [Privacy](/privacy.html).

## Remove

Drag the app from Applications to the Trash. Your data files are not touched.

## If something goes wrong

See [Troubleshooting](/docs/electron-microscopy-studio/troubleshooting.html), or write to <a href="mailto:mail@mac4dstem.com">mail@mac4dstem.com</a>.
